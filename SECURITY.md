# Kebijakan keamanan

## Melaporkan kerentanan

Jangan membuka issue publik untuk dugaan kerentanan, credential bocor, atau data
pengguna. Laporkan secara privat melalui **Security → Advisories → New draft
security advisory** pada repository GitHub ini.

Sertakan komponen terdampak, langkah reproduksi, dampak yang terlihat, dan saran
mitigasi bila tersedia. Jangan menyertakan secret production atau data pribadi
pengguna dalam laporan.

## Versi yang didukung

Hanya rilis minor terbaru pada major version yang aktif yang menerima perbaikan
keamanan.
